# AI Travel Planner (MVP)

A simple, working travel planning API that generates realistic trip itineraries based on budget, duration, and preferences.  
The system uses deterministic logic to select flights, hotels, and activities from curated datasets.  
It ensures the final plan is usable by validating budget constraints and daily activity limits.  
Built with FastAPI, the project focuses on correctness and practicality over complexity.  
No external APIs are used in the MVP — all recommendations come from structured mock data.  
Designed as a foundation that can later scale into a full multi-agent or real-time system.
